# Proposal

## Why

公司頁上線後，目前只能從產品詳情、比較表或搜尋結果點業者／製造廠名稱進入，沒辦法直接瀏覽「有哪些公司」，也沒辦法只知道公司名稱的一部分就找到它。成分已經有「成分總覽」當入口，公司也需要對應的總覽頁。資料中共有 600 家公司，其中 410 家已經沒有任何未失效的許可證，總覽頁需要預設把仍在營運的公司放在眼前，避免使用者翻過一長串已無有效產品的公司。

## What Changes

- 新增公司總覽頁 `/companies`：列出所有擔任過申請業者或製造廠的公司，每家顯示產品數、未失效許可證數，以及擔任申請業者與製造廠的產品數，點選進入該公司的公司頁。
- 總覽頁提供名稱快速過濾（中英文、不分大小寫、忽略多餘空白）、角色篩選（全部／申請業者／製造廠）、排序（產品數、未失效許可證數、名稱）。
- 預設只列出仍有未失效許可證的公司（目前 190 家），提供「包含已無有效許可證的公司」勾選項，並顯示目前列出的公司數與總數。
- 網站導覽列新增「公司總覽」。
- 公司頁「找不到此公司」的連結改為前往公司總覽，與成分頁找不到成分時連到成分總覽一致。
- 修正成分總覽：標題寫「最常用成分 (Top 80)」，實際卻列出全部 2,694 項，頁面 HTML 約 1.9MB。改為預設只顯示前 80 項並提供「顯示全部」按鈕，過濾框仍比對全部成分；卡片樣式改用 CSS class 取代每張卡片重複的 inline style，縮小頁面。
- 建置時產出公司摘要清單，供總覽頁在建置階段直接渲染；建置驗證新增總覽頁檢查。

## Capabilities

### New Capabilities

（無）

### Modified Capabilities

- `company-browse`：新增公司總覽頁的需求；公司頁查無公司時的連結改為公司總覽。
- `ingredient-browse`：新增成分總覽頁的需求（目前規格未涵蓋）：預設前 80 項、可展開全部、過濾比對全部成分。

## Impact

- 頁面：新增 `src/pages/companies.astro`；`src/pages/ingredients.astro` 改為預設前 80 項並改用 CSS class；`src/layouts/Layout.astro` 導覽列新增連結；`src/pages/company/index.astro` 修改 notFound 連結。
- 腳本：`scripts/build-shards.ts` 額外輸出 `data/companies.json`；`scripts/verify-release.ts` 新增檢查。
- 設定：`.gitignore` 加入 `data/companies.json`（與其他 ETL 產出一致，不進版控）。
- 建置產出：新增一個靜態頁面，約 600 筆公司項目，預估 HTML 約 250KB；成分總覽 HTML 預估從約 1.9MB 降到 500KB 以下。
- 相依套件：不新增。
