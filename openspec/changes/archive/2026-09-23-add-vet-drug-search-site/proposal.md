## Why

農業部「動物用藥資訊」開放資料（data.moa.gov.tw，id=023）收錄約 13,700 張動物用藥品許可證，但只提供原始 API／CSV：成分欄是夾雜 HTML 的自由文字，適用物種埋在適應症敘述中，也無法依成分歸類或並排比較。獸醫與養殖戶實務上最常問的是「這個成分有哪些產品可以用在我的動物上？」與「這幾個產品差在哪？」，目前沒有工具能直接回答。

## What Changes

- 新增每週自動執行的資料擷取流程：以分頁（`$top`／`$skip`）抓取完整資料（API 預設在 9,999 筆靜默截斷，實際約 13,739 筆），筆數異常時流程失敗、不發布。
- 新增資料清理與標準化：去除 HTML、民國日期轉換、許可證狀態判定、國產／輸入判定、劑型分層、成分抽取（搭配人工維護的前 200 大成分同義詞表）、物種抽取並保留「不含產蛋中之蛋雞／蛋鴨」等使用限制。
- 新增靜態查詢網站（Astro），目標使用者為獸醫與養殖戶，行動裝置優先：
  - 全文搜尋（中英文品名、成分、業者、許可證字號、適應症），瀏覽器端執行，支援中文。
  - 篩選：物種、劑型、單方／複方、國產／輸入、許可證狀態；生物製劑、原料藥、外銷專用預設不列入。
  - 成分頁（A：同成分找產品）：依單方／複方 → 劑型 → 物種分組。
  - 產品詳情頁：完整欄位與結構化的物種／限制／適應症。
  - 比較頁（C：勾選並排比較）：最多 3 項，以物種矩陣為主，網址可分享。
- 各頁面顯示免責聲明、資料來源與授權、資料更新時間。
- 不在本次範圍：停藥期、用法用量、疫苗依菌株或疾病歸類、LLM 輔助抽取、濃度結構化比較、會員與收藏功能。

## Capabilities

### New Capabilities

- `data-ingestion`：從 MOA API 分頁抓取完整資料、筆數防呆、每週排程與建置觸發。
- `data-normalization`：欄位清理、日期與狀態、國產／輸入、劑型分層、成分抽取與同義詞對照、物種與使用限制抽取、產品分類（一般藥品／生物製劑／原料藥）。
- `drug-search`：搜尋與篩選，含預設排除規則與蛋雞／蛋鴨限制的處理。
- `ingredient-browse`：成分頁，依單方／複方、劑型、物種分組列出產品。
- `product-detail`：單一產品詳情頁與穩定網址。
- `drug-comparison`：勾選產品並排比較（最多 3 項）、物種矩陣、可分享網址。
- `data-attribution`：免責聲明、資料來源與授權標示、更新時間。

### Modified Capabilities

（無，本專案目前沒有既有 spec。）

## Impact

- 全新專案，無既有程式碼。
- 新增相依：Astro、MiniSearch，以及 Node.js／TypeScript 的 ETL 腳本。
- 新增 GitHub Actions 工作流程（每週排程抓取、建置、部署），部署到靜態主機（GitHub Pages 或 Cloudflare Pages）。
- 外部相依：data.moa.gov.tw API 的可用性與欄位格式穩定性。
- 需人工維護的資料：成分同義詞表、物種對照表。
