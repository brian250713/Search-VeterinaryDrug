# Proposal

## Why

獸醫師與養殖戶常以廠商為單位找藥，例如「這家代理商還有哪些產品」「這個製造廠做過哪些劑型」。目前產品詳情頁的申請業者與製造廠只是純文字，想看同一家公司的其他產品只能回搜尋頁打關鍵字，而且搜尋無法區分這家公司是申請業者還是製造廠。資料中共有約 600 家公司（申請業者 408 家、製造廠 346 家），單一公司最多有 343 張許可證，很適合用和成分頁一樣的瀏覽頁呈現。

## What Changes

- 新增公司頁 `/company/?name=<公司名稱>`：單一殼頁，瀏覽器依名稱讀取公司分片後渲染。一家公司不論擔任申請業者或製造廠，都在同一頁呈現，可以篩選角色（全部／申請業者／製造廠）。
- 公司頁列出所有類別的產品（一般藥品、生物製劑、原料藥）。預設只顯示一般藥品且不含已失效許可證，可勾選「包含生物製劑」「包含原料藥」「包含已失效」展開。
- 公司頁沿用成分頁的呈現方式：單方／複方 → 劑型大類分組、物種／劑型／國產輸入篩選、蛋雞／蛋鴨限制處理、加入比較，以及載入中、找不到、載入失敗三種狀態與動態頁面標題。
- 產品詳情頁、比較表、搜尋結果與成分頁產品卡片中的申請業者與製造廠名稱改為連結，連到對應的公司頁；名稱空白（顯示「未載明」）時不加連結。
- 新增公司資料分片：建置時依公司名稱（去除前後空白、連續空白合併為一個）分到 64 個 JSON 分片（`/data/company/NNN.json`），每項產品記錄該公司在此產品中的角色。
- 成分頁與公司頁共用產品清單的篩選、分組與卡片渲染邏輯，避免兩份實作分歧；成分頁行為維持不變。
- 建置驗證腳本新增公司分片與公司殼頁的檢查。

## Capabilities

### New Capabilities

- `company-browse`：以申請業者／製造廠為入口的瀏覽體驗，包括公司頁的網址與資料載入、角色與類別篩選、分組呈現、加入比較，以及全站連到公司頁的入口。

### Modified Capabilities

- `product-detail`：詳情內容中的業者名稱與製造廠名稱改為連到公司頁的連結。

## Impact

- 頁面：新增 `src/pages/company/index.astro`；調整 `src/lib/render-product.ts`（詳情頁）、`src/pages/compare.astro`、`src/pages/index.astro`、`src/pages/ingredient/index.astro` 的業者與製造廠顯示。
- 共用模組：`src/lib/url.ts` 新增 `companyUrl()`；`src/lib/shard.ts` 新增 `COMPANY_SHARDS`；新增公司名稱正規化函式與成分頁／公司頁共用的產品清單模組。
- 型別：`src/types/drug.ts` 新增公司分片型別，`ProductSummary` 新增 `factoryName`。
- 腳本：`scripts/build-shards.ts` 產生公司分片；`scripts/verify-release.ts` 新增檢查。
- 建置產出：新增 64 個公司分片，總計約 11MB（未壓縮），單片平均約 170KB；新增一個 HTML 殼頁。
- 相依套件：不新增。
